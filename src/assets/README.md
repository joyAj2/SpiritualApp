# Assets

This directory contains static assets for the application.

## Structure

- `images/` - Image files (PNG, JPG, SVG, etc.)
- `icons/` - Icon files
- `fonts/` - Custom font files
- `videos/` - Video files (if needed)

## Usage

Import assets in your components:

```typescript
import logo from '../assets/images/logo.png'
import { ReactComponent as Icon } from '../assets/icons/icon.svg'
```
